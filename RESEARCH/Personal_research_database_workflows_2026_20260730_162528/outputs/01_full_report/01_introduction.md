# 1. 질문과 조사 범위

질문은 “개인 연구자가 최신 자료를 자동 수집하고, 중복을 제거하고, AI가 내용을 정리해 DB와 Obsidian에 쌓는 방식을 실제로 사용하는가?”이다.

공식 Zotero·Obsidian 문서, 현재 사용 가능한 통합 플러그인, 2026년 공개 개인 프로젝트, 로컬 우선 문헌 에이전트, 피어리뷰 문헌 합성 시스템을 비교했다. 소셜미디어 반응이나 상업 도구의 자기주장은 핵심 근거에서 제외했다.

Zotero는 데스크톱 로컬 API와 Web API를 제공하며 라이브러리 버전을 이용한 변경분 동기화를 지원한다. Obsidian은 로컬 폴더의 Markdown 파일을 원본으로 사용하고 외부 도구가 파일을 수정하면 반영한다. 이 두 기능은 자동화 파이프라인의 입력·출력 경계로 사용하기 적합하다.
