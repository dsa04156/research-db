### 오늘 바뀐 지식

- Agent 운영의 공통 분모는 model 성능보다 **외부 control plane**이다. Harness에는 eval gate, Kubernetes에는 resource claim·network API, agent runtime에는 sandbox가 같은 역할을 한다.
- GPU 공유는 exporter 유무만의 문제가 아니다. Scheduling 단계가 device topology와 claim을 이해하고 hardware partition을 강제해야 한다.
- Edge 쪽은 큰 구조 변화가 확인되지 않았다. 공개 SNS에서는 학습 자료와 소형 데모 관심만 보였고 production 확산 근거는 없었다.
