### 검증된 핵심 사실

- Kubernetes v1.37은 실행 중인 고우선순위 Pod의 리사이즈가 노드 용량 부족으로 `Deferred`일 때, 같은 노드의 저우선순위 Pod를 선점해 공간을 확보하는 Alpha 기능을 추가했다. 기본 비활성화이며 표준 배치 선점과 달리 현재 노드 안에서만 동작한다. [[vault/Sources/Kubernetes v1.37 Scheduler Preemption for In-Place Pod Resize (Alpha) -- R002797]]
- AWS는 백그라운드 에이전트 작업을 메일함처럼 관리하는 오픈소스 Pizza Bot을 공개했다. 완료 작업은 Unread, 사람 결정이 필요한 작업은 Action에 들어가며, 스케줄·웹훅·MCP·Agent Skills를 지원한다. AWS 서비스가 아닌 커뮤니티 프로젝트라 지원과 SLA는 없다. [[vault/Sources/Introducing Pizza Bot, an open source inbox for AI agents that work in the background -- R002804]]

### 초기 연구·추가 검증 필요

- Grounding Agent Memory는 완료된 실행 기록만 보고 메모리를 정리하면 오류와 낡은 지식을 보존할 수 있다고 지적하고, 최소 권한의 읽기 전용 도구로 환경을 다시 확인하는 curator를 제안한다. 논문이 보고한 성능·비용 수치는 독립 재현 전이다. [[vault/Sources/Grounding Agent Memory Environment-Probing Curation for Enterprise Agents -- R002789]]
- A2ABreak는 A2A 명세를 상태 기계로 모델링해 명세를 준수하는 공격자도 악용할 수 있다는 11개 취약점을 보고한다. 구현 취약점이 아니라 명세 분석 결과이며 전문가 검토 수치도 단일 연구 결과다. [[vault/Sources/A2ABreak Systematic Security Analysis of the A2A Protocol -- R002792]]
- Agent Incident Registry는 공개 사고와 연구 데모를 출처·기전·결과별로 기록하려는 시도다. 저자도 이 표본으로 실제 배포 실패율이나 통제 효과를 추정할 수 없다고 명시한다. [[vault/Sources/The Agent Incident Registry Toward Preventing Repeated AI Agent Failures -- R002790]]

### 추론

- 오늘 자료는 장기 실행 에이전트의 핵심이 대화 UI보다 지속 상태, 사람 승인 대기열, 검증 가능한 메모리, 프로토콜 경계로 이동하고 있음을 보여준다. 이는 여러 자료를 종합한 방향성 해석이다.
- Kubernetes 리사이즈 선점은 AI 추론 Pod의 증설 지연을 줄일 수 있지만, 낮은 우선순위 워크로드의 중단 비용과 노드 자동 확장 정책을 함께 설계해야 한다.

### SNS·커뮤니티 lead_only

- HN·Reddit에서는 모든 도구 스키마를 매 턴 보내는 비용, 브라우저 로그인 실패, 사람 상담원 인계, 하니스의 비신뢰 입력 처리가 반복됐다. 서로 다른 주장과 프로젝트가 섞여 있어 확인된 트렌드로 승격하지 않았다.
- Threads는 `edge ai`에서 일부 결과가 있었지만 기술 원문으로 확인할 수 있는 신규 발표는 없었다. 나머지 6개 전용 질의는 no-results였다.
- quick 모드에서 Reddit·HN만 실질 결과가 확인됐다. 다른 플랫폼은 미확인 상태이며 X/Twitter는 제외했다.
