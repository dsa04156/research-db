### 오늘의 핵심 자료

#### 1. [[vault/Sources/Kubernetes v1.37 Garhwal -- R002365|Kubernetes v1.37: Garhwal]]

- **핵심 요약:** Kubernetes v1.37이 67개 개선 사항과 함께 정식 공개됐다. HPA의 0개 파드 축소와 gang scheduling이 Beta로 올라갔고, DRA 확장 리소스·장치 taint/toleration은 Stable이 됐다.
- **왜 중요한가:** 유휴 GPU·배치 워크로드의 비용 절감과 여러 파드를 한 묶음으로 배치하는 AI/HPC 스케줄링이 기본 Kubernetes에 더 가까워졌다.
- **인프라·운영 영향:** 외부·객체 메트릭 기반 HPA는 `minReplicas: 0`을 시험할 수 있다. 컨트롤러는 API 서버의 `429 Retry-After`와 지수 백오프를 제대로 처리해야 한다.
- **근거 수준:** 공식 릴리스, A급. Confidence: High.
- **반증·한계:** Beta 기능은 운영 환경에서 별도 feature gate·호환 런타임·부하 시험이 필요하며, CPU·메모리 메트릭만으로는 0개 축소가 지원되지 않는다. [원문](https://kubernetes.io/blog/2026/08/26/kubernetes-v1-37-release/)

#### 2. [[vault/Sources/VMs won't contain cyber-capable agents -- R002375|VMs won't contain cyber-capable agents]]

- **핵심 요약:** Trail of Bits는 허가된 시험에서 GPT-5.6-Cyber가 QEMU/KVM VM을 세 차례 탈출했다고 보고했다. 알려진 취약점, 배포판에 늦게 반영된 패치, 당시의 0-day가 함께 사용됐다.
- **왜 중요한가:** 강한 도구 권한을 가진 에이전트에서 VM 하나만을 최종 보안 경계로 삼는 설계가 부족할 수 있다는 구체적 사례다.
- **인프라·운영 영향:** 네트워크와 자격증명 최소화, 최신 upstream 패치, 실행 시간 제한, 일회성 환경, 외부 감시를 겹쳐야 한다.
- **근거 수준:** 보안 연구기관의 1차 기술 보고와 HN·Reddit 독립 반응. Confidence: Medium-High.
- **반증·한계:** 세부 exploit 전체가 공개되거나 독립 재현된 것은 아니며, 특수한 사이버 모델과 시험 호스트에서 나온 단일 사례다. [원문](https://blog.trailofbits.com/2026/08/26/vms-wont-contain-cyber-capable-agents/)

#### 3. [[vault/Sources/JIT-Agent Scaling Harness Intelligence via Just-in-Time Harness Evolution -- R002331|JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution]]

- **핵심 요약:** JIT-Agent는 작업마다 메모리·계획·도구·실행 루프를 조합하고, 실행 신호로 하네스를 수리·진화시키는 전용 모델을 제안한다.
- **왜 중요한가:** 모델 가중치를 바꾸지 않고 하네스를 작업별로 생성하는 방향을 직접 평가했다는 점에서 self-evolving harness의 강한 연구 신호다.
- **인프라·운영 영향:** 하네스 변경을 코드처럼 버전 관리하고, 숨겨진 선택 과제와 회귀 평가를 통과한 변경만 승격하는 구조가 필요하다.
- **근거 수준:** 최신 arXiv 사전논문, 공개된 저자 실험. Confidence: Medium.
- **반증·한계:** DeepSeek-V4-Flash가 일부 벤치마크에서 GPT-5.6을 앞섰다는 수치와 다른 모델의 최대 +20.2점 향상은 독립 재현 전까지 초기 결과로 봐야 한다. [원문](https://arxiv.org/abs/2608.25593v1)

#### 4. [[vault/Sources/Serve Markdown to AI Agents with Accept Headers -- R002376|Serve Markdown to AI Agents with Accept Headers]]

- **핵심 요약:** 같은 URL에서 `Accept: text/markdown` 요청에는 Markdown을, 브라우저에는 HTML을 주는 콘텐츠 협상 패턴이 제안됐다. `Vary: Accept`, q-value, `406` 처리까지 구현 체크리스트를 제공한다.
- **왜 중요한가:** 에이전트가 DOM·광고·내비게이션을 걷어내는 비용 없이 본문을 바로 받게 해 검색·RAG 입력을 단순화할 수 있다.
- **인프라·운영 영향:** 캐시 키가 Accept 헤더를 구분하는지, HTML과 Markdown의 의미가 일치하는지, 기존 크롤러와 CDN이 깨지지 않는지 확인해야 한다.
- **근거 수준:** 프로젝트 문서와 HN·Reddit 반응. Confidence: Medium.
- **반증·한계:** 토큰·지연 절감은 합리적 추론이지만 독립적인 대규모 운영 측정은 아직 확인하지 못했다. [원문](https://acceptmarkdown.com/)

#### 5. [[vault/Sources/The Harness Is the Thing -- R002377|The Harness Is the Thing]]

- **핵심 요약:** 한 개발자가 Cursor·Claude·Pi 사이에 공통 Skills와 `AGENTS.md`, 계획 DAG, worker/critic/promoter 단계를 둔 개인 하네스를 공개했다.
- **왜 중요한가:** 모델 제품보다 재사용 가능한 실행 규칙·스크립트·감사 가능한 산출물 디렉터리가 실제 작업 경험을 통일한다는 현장 사례다.
- **인프라·운영 영향:** 반복 작업은 스크립트로 내리고, frontier 모델은 계획과 어려운 판단에 제한하며, 산출물 경계를 명시하는 운영 패턴을 시험할 가치가 있다.
- **근거 수준:** 독립 개발자 1차 경험담. Confidence: Medium-Low.
- **반증·한계:** frontier 모델 사용량 75% 감소는 한 사용자의 관찰이며 통제된 비용 실험이 아니다. [원문](https://scott-fryxell.github.io/blog/the-harness-is-the-thing/)
