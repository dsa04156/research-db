   - **핵심 요약:** agent의 모델·도구 호출은 고카디널리티 trace를 급증시킨다. 성공 호출은 샘플링하고 실패·재시도·정책 위반·느린 trace는 보존하는 pipeline-first 접근이 제안됐다.
   - **인프라·운영 영향:** `agent_id`, `tool_name`, `trace_id`, token·추정비용을 수집하되 저장 전 redaction과 목적별 retention을 적용할 필요가 있다.
   - **근거 수준:** 업계 분석(B), Confidence **Medium**. 9.5배 증가와 비용 절감 수치는 공급업체 의뢰 조사·사례이므로 일반 사실로 쓰지 않는다.

### 오늘 바뀐 지식

- **검증 사실:** 지속형 하네스, 로컬 완결형 agent runtime, 차세대 엣지 하드웨어가 같은 날 공식 발표로 확인됐다.
- **추론:** agent 인프라의 경쟁축이 단순 모델 성능에서 지속 실행의 복구성, 관측 비용, 로컬·클라우드 경계 설계로 이동하고 있다.
- **Lead-only:** 도구 수 제한, agent 대 결정적 workflow, 운영 신뢰 하락 논의가 HN·Reddit에서 동시에 늘었지만 서로 다른 글이 한 군집으로 섞여 상승 강도는 추가 확인이 필요하다.
