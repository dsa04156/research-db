### 검증된 사실

- Kubernetes v1.37은 `emptyDir` 권한 모드와 볼륨 bind mount의 `noexec`·`nosuid`·`nodev` 옵션을 Alpha 기능으로 추가했다. writable volume을 통한 실행과 공유 디렉터리의 임의 삭제를 줄일 수 있지만 feature gate와 런타임 지원 확인이 필요하다. [[vault/Sources/Kubernetes v1.37 Hardening Container Storage with Bind Mount Options and EmptyDir Permissions -- R002850]]
- NVIDIA는 Rust로 GPU 커널을 작성하는 `cuda-oxide`와 `cutile-rs` 두 경로를 공개했다. 전자는 초기 알파이고 후자는 stable Rust를 쓰므로, CUDA C++ 대체로 단정하기보다 도구 성숙도와 실제 성능을 따로 평가해야 한다. [[vault/Sources/Introducing CUDA Rust Two Tracks for Writing GPU Kernels -- R002883]]
- OpenAI는 광고 클릭 뒤 기업 후원 에이전트와 별도 대화를 시작하는 Sponsored Agents의 제한적 미국 시험을 발표했다. 일반 ChatGPT 답변과 분리되고 후원 표시가 붙는다. [[vault/Sources/Reimagining advertising with AI -- R002882]]

### 초기 연구와 추론

- HarnessTax는 같은 모델이라도 하네스가 비용과 초기 컨텍스트 크기를 크게 바꿀 수 있다고 보고했다. 다만 공개 벤치마크 두 종류 중심이며 보안·샌드박싱·장기 작업 비용이 충분히 반영되지 않았다는 반론이 있어, 모델 단독 순위보다 모델-하네스 쌍을 측정해야 한다는 방향성만 채택한다. [[vault/Sources/HarnessTax How Much Does the Harness Matter for Coding Agents -- R002885]]
- 장기 에이전트 궤적 연구는 최종 성공 여부만으로는 첫 실수와 회복 여부, 중간 피해를 잡기 어렵다고 보고했다. 2,518개 궤적과 6,967개 오류를 분석한 저자 결과이므로 독립 재현 전에는 수치를 일반화하지 않는다. [[vault/Sources/Locating Hidden Failures Makes Long-Horizon Agents More Reliable -- R002828]]
- 에이전트가 인프라 변경을 실행하기 전에 위험별 증거를 요구하는 Cognitive Admission Control은 정책·증거·dispatch guard를 한 계약으로 묶는다. 현재 결과는 로컬 통제 실험이며 생산 장애율을 뜻하지 않는다. [[vault/Sources/Cognitive Admission Control Risk-Conditioned Assurance for Consequential Actions in Agentic Dist -- R002880]]
- 멀티테넌트 도구에서는 tenant 값을 모델 입력으로 받기보다 검증된 자격증명에 범위를 묶고 에이전트 아래 계층에서 강제하는 구조가 더 안전하다는 초기 연구가 나왔다. [[vault/Sources/The Stochastic Deputy Structural Tenant Isolation for Tool-Using LLM Agents -- R002884]]
