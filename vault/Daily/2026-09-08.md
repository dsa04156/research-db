### 확인된 사실

- 에이전트의 운영 전환에서는 자동 평가, 결함 분류, 실행 trace와 승인 경계가 모델 교체만큼 중요해지고 있다. InfoQ 발표, 거버넌스 사전논문, 독립 기술 분석을 교차 확인했다.
- Kubernetes v1.37 rootless beta, kagent v0.10.0, Red Hat RHACS 고가용성 참조 구조는 최소권한·세션 내구성·보안 CI 가용성을 실제 기능으로 강화한다.
- Netflix Flink autoscaler 사례는 상태ful 작업의 상태를 읽는 자동화가 단순 cluster CPU 기반 제어를 보완한다는 운영 방향을 보여준다.

### 추론

- 이번 주 자료의 공통점은 모델 출력보다 실행 상태, 소유권, 실패 후 복구와 서비스별 운영 신호를 하네스가 책임진다는 점이다.
- 시드 글의 model–harness–environment 분리는 Kubernetes 권한 경계와 autoscaler 제어 신호까지 포함하는 control plane 문제로 확장되고 있다.

### 초기 연구·미확정

- Environment Evolution, Substrate-Aware Agents, GreenPipe의 성능·전력 수치는 단일 사전논문 결과라 독립 재현 전이다.
- HydraFusion의 비용·품질 효과는 GitHub 자체 오프라인 평가이며 실사용 자료가 부족하다.

### lead_only와 반증

- HN·Reddit의 에이전트 게시판, 장애 대응 역량 저하, 하니스 과설계 반작용은 조사 질문으로 유지한다.
- Threads의 DeerFlow 2.0과 edge AI 글은 공식 원문 확인 전 lead_only다.
- discovery가 동명·무관 인기 영상을 같은 군집에 합쳐 교차 플랫폼 수를 과대계상했으므로 확정 트렌드로 사용하지 않았다.
