### 검증된 사실

- Kubernetes v1.37에서 `KubeletInUserNamespace`가 베타로 승격됐다. 이 기능은 kubelet·CRI/OCI 런타임·CNI·kube-proxy를 호스트의 비-root 사용자로 실행할 수 있게 한다. 기능 게이트는 기본 활성화되지만 기존 클러스터가 자동으로 rootless로 바뀌지는 않으며, 일부 CNI·CSI 호환성 제약은 남아 있다. [[vault/Sources/Kubernetes v1.37 KubeletInUserNamespace (aka Rootless mode) Graduates to Beta -- R002631]]
- kagent v0.10.0 정식 릴리스에는 스트리밍 유휴 시간 설정, Helm 서비스 주석, 채팅 세션 공유, `SandboxAgent`의 BYO·Python 런타임 지원이 포함됐다. [[vault/Sources/kagent-dev kagent v0.10.0 -- R002643]]
- GitHub는 여러 모델을 선택적으로 조합하는 HydraFusion을 Copilot 연구 프리뷰로 공개했다. 공식 글의 품질·비용 수치는 통제된 오프라인 벤치마크 결과이며 실제 개발 환경에서의 재현은 아직 확인 전이다. [[vault/Sources/Project HydraFusion Frontier quality via multi-model orchestration -- R002636]]

### 초기 연구와 해석

- `Environment Evolution`은 에이전트가 약점을 드러낸 환경을 점진적으로 더 어렵게 만드는 루프를 제안한다. harness를 고정 도구가 아니라 학습 난이도를 조절하는 시스템으로 본다는 점이 중요하지만, 14.4·18.0%p 향상은 저자 실험과 특정 모델·벤치마크에 한정된 사전논문 결과다. [[vault/Sources/Environment Evolution for Terminal Agents -- R002607]]
- `Substrate-Aware Agents`는 메모리·시간·런타임 제약을 계획 입력에 넣으면 구현 선택이 달라진다고 보고했다. 운영 계약을 프롬프트가 아닌 실행 상태의 일부로 취급해야 한다는 설계 신호지만 단일 과제와 저자 실험이라 일반화는 미확정이다. [[vault/Sources/Substrate-Aware AI Agents Execution Context as a First-Class Input -- R002610]]
- PatchBench는 단순히 PoC 크래시가 사라지는지만 보는 패치 평가가 암기와 표면적 우회를 놓칠 수 있다고 지적한다. 프로덕션 에이전트 평가는 결과 성공 여부뿐 아니라 원인 수정·패치 유사도·변형 입력까지 검사해야 한다. [[vault/Sources/PatchBench Evaluating AI Agents for Vulnerability Patching -- R002620]]
- GreenPipe는 K3s와 Raspberry Pi 4에서 컨테이너별 DNN 추론 전력을 추정했다. Edge AI 스케줄링에 에너지/추론 지표를 넣을 근거지만, 제한된 하드웨어와 워크숍 논문 결과다. [[vault/Sources/GreenPipe Power Modeling for Containerized DNN Inference on Kubernetes Edge Nodes -- R002627]]

### SNS 신호와 보류

- Reddit·HN에서 복잡한 harness를 크게 만든 뒤 단순화했다는 경험담이 함께 잡혔다. 다만 발견기가 비용·검증·보안 논점을 하나의 군집으로 섞었고 게시물이 독립 사례인지도 불분명해 `과열·미확정`으로 둔다.
- Threads의 “agent harness 명세를 여러 모델이 제대로 구현하지 못했다”는 글은 능력의 불균일성을 보여주는 경험담일 뿐 검증된 비교가 아니다. [[vault/Sources/I tried giving a software spec for an agent harness to Astra 6, Fable 5.1, Muse Spark 1.3, and G -- R002648]]
- Edge AI가 하이브리드 클라우드를 10배 빠르게 한다는 주장과 Azure가 미확인 `Astra` 모델을 채택했다는 주장은 공식 근거를 찾지 못했다. 둘 다 `lead_only`로 유지하며 핵심 결론에 사용하지 않는다.

### 오늘의 우선순위

1. rootless 노드는 별도 풀에서 CNI·CSI·권한 요구 워크로드를 호환성 시험한다.
2. 에이전트 실행 계약에 시간·메모리·비용 상한을 명시하고 평가 로그에 실제 준수 여부를 남긴다.
3. 보안 패치 평가는 단일 PoC 통과가 아니라 변형 입력과 근본 원인 수정 여부까지 포함한다.
