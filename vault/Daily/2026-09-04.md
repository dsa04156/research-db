### 검증된 핵심 변화

1. **에이전트 하네스 자체가 연구 대상이 됐다.** [[vault/Sources/HarnessDev Can LLMs Create and Evolve Their Own Agent Harness -- R002563|HarnessDev]]는 모델 가중치를 고정해도 실행 하네스 변경이 성능을 크게 바꿀 수 있다는 문제를 정식 평가 대상으로 제시한다. 다만 신규 프리프린트이므로 수치와 일반화는 후속 재현이 필요하다.
2. **자기개선의 판정자를 LLM 하나에 맡기면 안 된다는 경고가 구체화됐다.** [[vault/Sources/LLM-as-a-Judge Is Not an Oracle Why Self-Improving Agents Need Deterministic Guardrails -- R002559|LLM-as-a-Judge Is Not an Oracle]]는 LLM 판정을 조언 신호로 낮추고 결정적 테스트와 정책 검사를 함께 두자는 설계를 제안한다.
3. **하네스 훅은 공급망·권한 경계로 봐야 한다.** [[vault/Sources/A Blind Trust, the Bloody Thrust When Attacker-Controlled Hook Updates Steer AI Agent Harnesses -- R002555|A Blind Trust, the Bloody Thrust]]는 라이프사이클 훅 설정 변경이 호스트 권한 명령으로 이어지는 공격면을 다룬다. 프리프린트 결과이지만, 훅 서명·변경 승인·실행 감사가 필요한 이유는 명확하다.
4. **Kubernetes의 GPU·가속기 자원 모델이 DRA 중심으로 성숙했다.** [[vault/Sources/Kubernetes v1.37 DRA Updates -- R002588|Kubernetes v1.37 DRA Updates]]에서 DRA Extended Resource 지원이 GA가 됐다. 기존 `vendor.com/gpu` 요청을 DRA 드라이버가 직접 충족할 수 있어 장치 플러그인과 DRA를 이중 운영하는 부담을 줄일 수 있다.
5. **상용 에이전트도 모델보다 하네스·승인 구조를 전면에 둔다.** [[vault/Sources/Building commerce agents with Claude -- R002606|Building commerce agents with Claude]]는 카탈로그 기반 도구, 반복 제한, 사람 승인, 배포 선택지를 묶은 공개 블루프린트를 제시했다. 성과 수치는 공급사 발표이므로 독립 검증 전까지 사실로 확대 해석하지 않는다.
