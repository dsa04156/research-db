### 해석

- 오늘의 공통 방향은 **모델 성능보다 실행 경계의 모듈화·추적성·운영 소유권**이다. DeepSeek는 하네스 내부 기능을 플러그인 경계로 만들고, LLMOps 글은 조직의 책임 경계를 플랫폼 API로 만들며, Oxide는 인프라 공급자별 차이를 Kubernetes 확장점으로 격리한다.
- [[vault/Sources/Adaptive AI Agent Migration via Generative Diffusion-based Reinforcement Learning in Edge Intell -- R001987|엣지 에이전트 마이그레이션 연구]]는 에이전트를 상태 없는 컨테이너처럼 옮길 수 없고 호출 이력·계획 문맥·메모리 저장소까지 다뤄야 한다고 본다. 문제 정의는 중요하지만 단일 논문의 시뮬레이션 수치는 독립 재현 전이다.
- [[vault/Sources/Bullet Fast, by design -- R002009|Bullet]]이 내세운 모델 라우팅·표적 문맥 검색·병렬 도구 실행·루프 차단은 하네스 최적화의 구체적인 축이다. 다만 비공개 베타이고 속도·생산성 수치는 공급자 주장이다. [원문](https://www.codewithbullet.com/)

### 약한 신호와 반증·한계

- DeepSeek Harness는 공식 원문과 HN·Reddit·Threads·TikTok에서 동시에 관측돼 ‘신규 공개’는 높은 신뢰도다. 그러나 높은 관심과 4만 개 이상의 GitHub 별은 안정성·보안·운영 성숙도를 증명하지 않는다.
- Reddit·HN에서는 에이전트 생산성의 병목을 모델보다 상태 관리, 연속성, 완료 검증으로 보는 논의가 반복됐다. 서로 다른 게시물이지만 통제된 생산성 측정은 아니다.
- 오늘 YouTube 검색은 6건을 반환했으나 모두 최근 24시간 영상이 아니고 자막도 확보되지 않았다. 신규 트렌드 근거에서 제외한다.
- TikTok의 ‘1만5천 달러 마케팅 부서’ 및 DeepSeek 성능 주장은 홍보성 `lead_only`다. engagement는 사실 근거로 사용하지 않는다.
- arXiv는 429·시간초과, Red Hat RSS는 XML 파싱 오류가 발생해 오늘 논문·공식 블로그 범위가 부분적이다.
