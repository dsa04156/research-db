## 오늘 꼭 볼 것

### 1. Kubernetes 저장소 보안이 Pod 명세 안으로 들어왔다 — ✅ 확인된 사실

**무슨 소식?** v1.37은 볼륨 bind mount에 `noexec`·`nosuid`·`nodev`를 지정하고 `emptyDir` 생성 권한을 설정하는 Alpha 기능을 추가했다. **왜 중요한가?** 읽기 전용 root filesystem을 써도 writable volume에서 악성 파일을 실행할 수 있던 빈틈과, sidecar가 다른 컨테이너 파일을 지울 수 있던 문제를 줄인다. **한계:** feature gate, Linux 노드, CRI 지원을 확인해야 한다. [[vault/Sources/Kubernetes v1.37 Hardening Container Storage with Bind Mount Options and EmptyDir Permissions -- R002850]] · [원문](https://kubernetes.io/blog/2026/09/16/kubernetes-v1-37-hardening-container-storage/)

### 2. 긴 작업은 “성공했나?”만 봐서는 부족하다 — ⚠️ 초기 연구·추가 검증 필요

**무슨 소식?** 연구진은 2,518개 에이전트 궤적에서 6,967개 실수를 78종으로 분류했고, 첫 오류 뒤 스스로 회복하거나 오류를 잡는 비율이 낮다고 보고했다. **왜 중요한가?** 최종 점수가 통과여도 데이터 삭제나 시스템 손상 같은 중간 피해가 남을 수 있어 단계별 검증기가 필요하다. [[vault/Sources/Locating Hidden Failures Makes Long-Horizon Agents More Reliable -- R002828]] · [원문](https://arxiv.org/abs/2609.17930)

### 3. 실행 권한과 실행 준비 증거를 분리한다 — ⚠️ 초기 연구·추가 검증 필요

**무슨 소식?** Cognitive Admission Control은 인프라 변경 전에 위험별 증거, 최신성, 독립 witness(증거 제공자), dispatch guard를 검사한다. **왜 중요한가?** “권한이 있다”와 “지금 실행해도 된다”를 분리해 에이전트의 고위험 동작을 정책으로 차단할 수 있다. **한계:** 로컬 통제 실험 결과다. [[vault/Sources/Cognitive Admission Control Risk-Conditioned Assurance for Consequential Actions in Agentic Dist -- R002880]] · [원문](https://arxiv.org/abs/2609.16313)

### 4. 엣지 에이전트 성능 주장이 커졌다 — ⚠️ 초기 연구·추가 검증 필요

**무슨 소식?** NVIDIA는 Jetson AGX Thor에서 TensorRT Edge-LLM이 MLPerf Edge Agentic 작업을 6.4배 빠르게 끝냈다고 발표했다. **왜 중요한가?** 차량·로봇처럼 지연과 연결성이 중요한 곳에서 cloud 호출을 줄일 가능성이 있다. **한계:** 공급사 벤치마크 수치라 독립 재현과 전력·정확도 조건 확인이 필요하다. [[vault/Sources/TensorRT Edge-LLM Completes the MLPerf Edge Agentic Benchmark 6.4x Faster on Jetson AGX Thor -- R002860]] · [원문](https://developer.nvidia.com/blog/tensorrt-edge-llm-completes-the-mlperf-edge-agentic-benchmark-6-4x-faster-on-jetson-agx-thor/)
