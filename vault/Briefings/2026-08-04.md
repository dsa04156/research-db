# 2026-08-04 오늘의 연구 브리핑

> **한 줄 결론:** 오늘은 AI agent를 잘 돌리는 핵심이 모델보다 GPU 자원 할당, 네트워크 표준, 실행 경로 검증 같은 바깥 운영 장치라는 점이 더 분명해졌다.

## 30초 요약

- Kubernetes에서 GPU를 통째로 배정하는 대신, DRA(동적 자원 할당)와 MIG(GPU 하드웨어 분할)를 함께 쓰는 구체적 방법이 공개됐다.
- Gateway API v1.6에서 TCP·UDP 경로가 정식 표준이 됐다.
- AI agent는 최종 답만 검사하면 부족하다. 도구 사용과 메모리 변경을 포함한 전체 실행 경로를 봐야 한다.

## 오늘 꼭 볼 것

### ✅ 확인된 사실 — GPU 한 장을 격리해서 나누는 방법

**무슨 소식?** Red Hat이 H100 한 장에 서로 격리된 LLM 서비스 두 개를 배치하는 DRA·MIG 예제를 공개했다.  
**왜 중요한가?** 비싼 GPU를 팀별로 안전하게 공유할 수 있는 실제 구성 순서가 생겼다. [[vault/Sources/Multitenant AI inference with dynamic resource allocation on OpenShift -- R001700|DB 노트]] · [원문](https://developers.redhat.com/articles/2026/08/03/multitenant-ai-inference-dynamic-resource-allocation-openshift)

### ✅ 확인된 사실 — TCP·UDP 경로가 정식 표준으로

**무슨 소식?** Gateway API v1.6에서 TCPRoute와 UDPRoute가 Standard v1으로 승격됐다.  
**왜 중요한가?** 데이터베이스·IoT·비HTTP 서비스가 제품별 전용 설정에 덜 묶인다. [[vault/Sources/Gateway API v1.6 TCPRoute and UDPRoute Graduate to Standard -- R001694|DB 노트]] · [원문](https://kubernetes.io/blog/2026/08/03/gateway-api-v1-6-release/)

### ⚠️ 초기 연구·추가 검증 필요 — Agent는 실행 과정까지 검사

**무슨 소식?** 새 survey는 답 한 번보다 도구 호출·메모리·시간에 따른 상태 변화가 이어지는 전체 경로를 검증해야 한다고 정리했다.  
**왜 중요한가?** 답이 맞아도 중간에 권한을 넘거나 잘못된 메모리를 남길 수 있다. [[vault/Sources/Beyond Component Testing Validating Agentic AI Systems -- R001682|DB 노트]] · [원문](https://arxiv.org/abs/2607.29405)
