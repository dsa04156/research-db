# 2026-09-04 오늘의 연구 브리핑

> **한 줄 결론:** 모델보다 하네스의 평가·권한·승인 구조가 핵심이었다.

## 30초 요약

- 에이전트가 자기 하네스를 고치는 연구가 늘면서, 무엇을 “개선”으로 인정할지에 대한 평가 장치가 중요해졌다.
- Kubernetes 1.37은 DRA(동적 자원 할당)를 통해 GPU 같은 장치를 기존 방식과 더 자연스럽게 연결한다.
- 커뮤니티에서는 거대한 에이전트 프레임워크보다 작은 실행 계층, 명시적 상태, 재현 가능한 평가를 선호하는 목소리가 반복됐다.

## 오늘 꼭 볼 것

### 1. 하네스를 스스로 바꾸는 에이전트를 어떻게 평가할까 — ⚠️ 초기 연구·추가 검증 필요

**무슨 소식?** HarnessDev는 모델을 고정하고 하네스만 바꿨을 때의 성능을 평가한다.  
**왜 중요한가?** 재현에는 모델뿐 아니라 하네스·예산·권한·평가 조건도 필요하다. 신규 프리프린트라 독립 재현은 아직 없다.  
[[vault/Sources/HarnessDev Can LLMs Create and Evolve Their Own Agent Harness -- R002563|Source]] · [원문](https://arxiv.org/abs/2609.01437)

### 2. LLM 심판을 최종 판정자로 두지 말라는 경고 — ⚠️ 초기 연구·추가 검증 필요

**무슨 소식?** 자기개선 결과를 같은 계열 LLM이 심사하면 심판 취향에 맞출 수 있다는 연구다.  
**왜 중요한가?** 회귀 테스트, 정책 검사, 비용 한도를 LLM 평가와 함께 둬야 한다.  
[[vault/Sources/LLM-as-a-Judge Is Not an Oracle Why Self-Improving Agents Need Deterministic Guardrails -- R002559|Source]] · [원문](https://arxiv.org/abs/2609.02246)

### 3. 에이전트 훅은 편의 기능이 아니라 권한 경계 — ⚠️ 초기 연구·추가 검증 필요

**무슨 소식?** 훅 설정이 변조되면 모델이 보지 못한 명령이 호스트 권한으로 실행될 수 있다는 분석이다.  
**왜 중요한가?** 훅 승인, 서명, 허용 명령, 실행 로그가 필요하다.  
[[vault/Sources/A Blind Trust, the Bloody Thrust When Attacker-Controlled Hook Updates Steer AI Agent Harnesses -- R002555|Source]] · [원문](https://arxiv.org/abs/2609.03884)

### 4. Kubernetes DRA의 기존 GPU 요청 연동이 정식 안정 단계로 — ✅ 확인된 사실

**무슨 소식?** Kubernetes 1.37에서 DRA Extended Resource가 GA가 됐다. 기존 GPU 요청을 DRA 드라이버가 직접 처리한다.  
**왜 중요한가?** 장치 플러그인과 DRA의 중복 운영을 줄일 수 있다.  
[[vault/Sources/Kubernetes v1.37 DRA Updates -- R002588|Source]] · [원문](https://kubernetes.io/blog/2026/09/03/kubernetes-v1-37-dra-updates/)

## 트렌드 레이더

- **상승 — 상거래 에이전트 참조 구현:** Anthropic 공식 원문과 HN·Reddit 반응이 확인됐다. 공개 예제는 사실이지만 성과 수치는 공급사 주장이다. [[vault/Sources/Building commerce agents with Claude -- R002606|Source]] · [원문](https://claude.com/blog/claude-for-commerce-agents) **Confidence: 높음(출시), 낮음(성과)**
- **유지 — 작고 명시적인 에이전트 실행 계층:** HN과 Reddit에서 프레임워크 복잡성·메모리 남용·평가 설계가 반복됐다. 서로 다른 주장이 섞여 있어 하나의 확정 추세로 과장하지 않는다. **Confidence: 중간**
- **상승 — 하네스 보안과 결정적 평가:** 여러 논문이 훅 권한과 LLM 심판 편향을 다뤘다. 프리프린트 중심이다. **Confidence: 중간**

## 분야별 추가 동향

- **Self-evolving harness:** CordisBench의 생명주기 추론 평가와 여러 날 개선 루프 연구가 나왔다. 둘 다 초기 연구다.
- **AI agents:** 최신 메모리와 낡은 계획이 공존하는 “stale plan” 문제가 제기됐다.
- **Kubernetes·Cloud·Edge:** 사용자 신원 전달, workerd 릴리스, 위성 간 분산 추론 연구가 확인됐다. 마지막 항목은 시뮬레이션 결과다.

## SNS·커뮤니티 신호

- Reddit·HN에서 하네스 구조와 평가 논점이 잡혔다. 빠른 모드가 두 플랫폼만 검색해 YouTube·LinkedIn·GitHub 등은 이번 회차 미확인이다.
- Threads는 7개 전용 질의 중 `edge ai`만 결과가 있었고, 4건 가운데 3건이 유사한 종목 문구였다. 사실 근거로 쓰지 않는다.
- 트렌드 탐색의 Reddit 상태는 `partial`이었다. 따라서 결과가 적다는 사실을 관심 부재로 해석하지 않는다.

## 바로 써먹을 점

- 하네스 변경마다 모델·도구·권한·평가셋 버전을 함께 저장한다.
- LLM 평가와 별도로 회귀 테스트, 비용 한도, 금지 행동 검사를 둔다.
- 훅 변경은 코드처럼 승인·서명·감사하고, GPU는 DRA 호환성을 먼저 시험한다.
