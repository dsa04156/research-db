## 지난 종합과 달라진 점

지난주는 공개 하네스와 테스트·격리·승인 기능이 제품 수준으로 내려오는 흐름이 중심이었다. 이번 주는 그 다음 단계다. 하네스를 crash recovery와 operation log를 가진 워크플로 런타임으로 정의하고, 같은 하네스를 강화학습 rollout 경계로 사용하려는 설계가 구체화됐다. 동시에 메모리 압축·주입·포렌식 연구가 늘어 “지속 상태를 어떻게 안전하게 남길 것인가”가 핵심 문제로 올라왔다.

## 분야별 핵심 변화

### Self-evolving harness

Pi는 durable run, lane, append-only tree, operation log, deterministic stepping을 설계 목표로 공개했다. TrueForge는 비슷한 책임을 실제 오픈소스 런타임과 로컬·호스티드 배포로 묶었다. Task-CoEvolve는 하네스 코드를 반복 수정할 때 평가 작업도 함께 선택해 비용을 줄이려 하지만 단일 연구 결과다.

### AI agents

Agent Lightning과 LEGO-RL은 하네스가 도구·컨텍스트·실행 피드백을 소유한 상태로 RL trainer와 연결되는 구조를 제시했다. 장기 메모리 쪽에서는 Compaction Cliff, InjecMEM, HANSARD가 규칙 손실·기억 주입·사후 증거 보존을 각각 문제 삼았다.

### Kubernetes

llm-d의 endpoint picker는 KV cache tracker, queue scorer, priority objective를 사용한다. 일반 Service의 round-robin이나 CPU/GPU 지표만으로는 cache-sensitive inference를 설명하기 어렵다. fail-open과 fail-close 선택도 가용성과 정책 준수 사이의 명시적 운영 결정이 됐다.

### Cloud·Distributed

workerd v1.20260825.1은 실행 중 WebSocket 자동 응답 보존을 수정했다. 에이전트와 edge worker 모두 장기 연결·스트림·세션의 수명주기 정합성이 새 기능보다 중요한 장애 축으로 반복된다.

### Edge AI

Thermo-FL은 Jetson 물리 테스트베드에서 장치 온도를 제어 신호로 사용해 LoRA 작업량과 통신 밀도를 조절한다. 아이디어는 운영 친화적이지만 독립 재현과 장기간 현장 결과가 없어 초기 연구로 유지한다.

## 분야를 가로지르는 연결

Pi의 operation log, Kubernetes의 endpoint picker, agent memory provenance, workerd의 WebSocket 수명은 모두 “중단되거나 상태가 바뀌었을 때 무엇을 다시 실행하고 무엇을 보존할 것인가”라는 같은 문제다. 모델·Pod·device보다 위에 있는 **상태 전이와 복구 계약**이 공통 인프라 계층으로 떠오르고 있다.

## 합의가 형성된 주장

- 장기 실행 에이전트에는 내구성 있는 작업 기록과 crash recovery 경계가 필요하다. Confidence: High.
- sandbox, approval, tool effect는 모델 추론과 분리된 하네스 정책이어야 한다. Confidence: High.
- 캐시 민감 LLM 추론은 일반 Kubernetes 부하분산보다 풍부한 요청·캐시 상태를 필요로 한다. Confidence: High.
- 하네스 평가에는 최종 답뿐 아니라 runtime trace, failure recovery와 비용이 포함돼야 한다. Confidence: Medium.

## 서로 충돌하는 주장

- “하네스가 곧 독립 플랫폼이 된다”는 방향성은 강하지만 Pi는 설계 브랜치이고 TrueForge의 대규모 운영 자료는 부족하다.
- RL 논문들은 큰 성능 향상을 보고하지만 독립 재현 전이다. 방향 신호와 성능 사실을 분리해야 한다.
- 커뮤니티는 SRE 에이전트를 진단 보조로 보는 쪽과, 자동화 전에 toil 자체를 제거해야 한다는 쪽으로 갈린다.

## Kubernetes·Cloud·Edge 운영 영향

- agent run을 durable operation으로 기록하고 tool effect를 operation ID 기반 멱등 처리한다.
- 복구 테스트는 모든 effect 경계에서 process close/reopen을 재현한다.
- 추론 라우터에 prefix-cache hit, queued tokens, prefill/decode, priority와 EPP failure를 관측한다.
- memory compaction에서 safety rule, secret, episodic log에 서로 다른 보존 정책을 둔다.
- edge 학습은 정확도뿐 아니라 온도, throttling, 전송량과 공격 내성을 함께 측정한다.
