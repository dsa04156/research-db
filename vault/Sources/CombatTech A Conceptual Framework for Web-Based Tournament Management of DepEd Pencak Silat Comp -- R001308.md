## 요약·초록

School-based Pencak Silat tournaments managed by the Department of Education (DepEd) remain on paper, resulting in delayed schedules, inconsistent scores, unverified results, and fragmented performance records. This issue showed that there is a lack of a structured digital framework for competitive school-based combative sports. This study presents CombatTech, or Combative Technology, as a conceptual model for a Web-based Competition Management System for DepEd-affiliated Pencak Silat competitions. The framework was created using a descriptive and developmental research method, and following the initiation phase and the data and requirements analysis phase of the Agile methodology. Semi-structured interview data from 10 stakeholders—seven from Laguna Province and three from Batangas—and non-participant field observations at three DepEd-sanctioned events, namely the Laguna Division Meet, Cabuyao City Meet, and Batangas District Meet, were used to gather data. Secondary data included document analyses of DepEd memos, Philippine Sports Commission guidelines, and PERSILAT competition rules. Semi-structured interview and non-participant observation data were analyzed using inductive thematic coding. Identified operational issues were mapped to the specified requirements for each layer. Six layers of this conceptual model are presented, which include a user interface layer, an application logic layer, a data management layer, a data analytics layer, a cloud infrastructure layer, and a security and access control layer. Each layer includes proposed specification details for future system development. Future studies may include developing a system for testing and evaluating user acceptability using the Technology Acceptance Model.
