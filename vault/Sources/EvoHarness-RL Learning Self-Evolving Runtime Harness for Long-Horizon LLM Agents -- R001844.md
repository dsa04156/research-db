## 요약·초록

EvoHarness-RL learns an offline harness policy that constructs and updates Belief, Progress, and Experience state during long-horizon execution. On ALFWorld with Qwen3-8B the authors report 96.9% success, but this is a single benchmark and model setting that still needs independent replication.
