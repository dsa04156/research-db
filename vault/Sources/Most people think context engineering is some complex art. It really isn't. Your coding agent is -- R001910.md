## 요약·초록

Most people think context engineering is some complex art. It really isn't. Your coding agent is just an LLM with a context window, and a harness like Claude Code overlays a system prompt and tool definitions you can't touch. The whole game is that anything that doesn't reach the context window literally does not exist to your agent. So your CLAUDE.md or agents.md file is the trunk, it loads automatically every single time, and from there you point to skills, scripts, MCP tools, and workflows like branches on a tree.
