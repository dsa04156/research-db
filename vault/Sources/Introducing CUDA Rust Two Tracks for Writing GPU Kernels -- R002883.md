## 요약·초록

NVIDIA는 Rust로 GPU 커널을 작성해 PTX로 컴파일하는 cuda-oxide와 stable Rust 기반 tile 추상화 cutile-rs를 공개했다. 두 경로 모두 메모리 안전성을 강조하지만 cuda-oxide는 초기 알파이고 도구 성숙도와 성능은 실제 워크로드 검증이 필요하다.
