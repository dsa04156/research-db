## 요약·초록

The rapid growth of distributed software architectures, characterized by microservices, event-driven messaging, and cloud-native orchestration has introduced a level of SDLC complexity that traditional human-only engineering teams struggle to manage at scale.Each phase of the software development life cycle, from requirements elicitation to deployment and post-production monitoring, demands specialized knowledge, meticulous documentation, and consistent execution across dozens of interdependent components.The combinatorial complexity of concerns such as distributed coordination, eventual consistency, schema evolution, and multi-tenant observability far outpaces the linear scaling of human engineering capacity.Meanwhile, the emergence of large language model (LLM)-powered autonomous agents offers a new paradigm: intelligent, goal-directed software entities capable of perceiving context, invoking tools, and producing artefacts within constrained operational boundaries.This paper proposes a conceptual model for integrating AI sub-agents and reusable skills into every phase of the SDLC in the context of distributed systems and data analysis pipelines.The model is structured around an orchestrator agent that decomposes high-level engineering goals into discrete tasks delegated to five specialised sub-agents: a Requirements Agent, a Code Generation Agent, a Testing Agent, a Deploy and Monitor Agent, and a Data Pipeline Agent, each operating through composable, reusable skills powered by LangChain and AWS Bedrock.Special attention is given to spec-based development as embodied by AWS Kiro, which enables formal specification artefacts to drive automated code generation, and to three orchestration patternssequential pipeline, parallel fan-out, and reflective critiquethat govern agent collaboration efficiency and correctness.The Data Analysis Pipeline is examined as a distinct SDLC sub-domain, covering Kafka-driven ingestion,
