## 요약·초록

Agent 시대의 핵심 경쟁은 Harness가 아니라 Control Plane이다. - 다음 AI Agent 시장의 사업을 준비하기 위한 글. 지금 Agent 시장은 언뜻 보면 서로 다른 제품군들이 경쟁하는 것처럼 보인다. Linear, Jira, ServiceNow는 프로젝트/업무 관리 소프트웨어다. Codex와 Claude는 모델 회사에서 시작했다. Cursor는 개발 환경에서 시작했고, Orca, Paseo, Pi 같은 제품은 여러 Agent와 모델을 연결하고 실행하는 Harness/ADE에 가깝다. 그런데 이들은 점점 같은 방향으로 움직이고 있다.
