## 요약·초록

Cloud Computing is a flexible platform allowing you to deploy and scale your applications with more ease than you would have on your own hardware. It allows virtual hosting with no need to get heavy - duty machinery. Small applications, actions that need to be performed from time to time, such as sending out email messages or generating thumbnails can now be handed over to virtual machines on a pay - as - you - go basis, there to be activated and deactivated on demand. Compared to traditional hosting where you need to rent your own machine and set everything up yourself, the cost of using cloud hosting is usually much smaller. Normally, you would need to set your application with a sufficient level of demand for capacity that you would keep a machine running for a whole month. With cloud computing, servers can ramp up or down or be turned off entirely at low demand times.
