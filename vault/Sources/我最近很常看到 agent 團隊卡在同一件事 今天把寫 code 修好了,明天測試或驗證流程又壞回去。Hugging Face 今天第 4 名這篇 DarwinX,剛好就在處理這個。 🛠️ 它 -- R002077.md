## 요약·초록

我最近很常看到 agent 團隊卡在同一件事：今天把寫 code 修好了，明天測試或驗證流程又壞回去。Hugging Face 今天第 4 名這篇 DarwinX，剛好就在處理這個。 🛠️ 它不重訓模型，改的是 agent harness，把 prompt、tools、skills、control flow 當成可持續演化的系統。 🔍 這篇我會多看兩眼，因為它盯的是 workflow 互相打架的 regression。你把 coding loop 調順了，規格理解、驗證流程或長任務穩定性卻一起後退，這種事真的很常見。 來源：Hugging Face / arXiv https://arxiv.org/abs/2608.07545
