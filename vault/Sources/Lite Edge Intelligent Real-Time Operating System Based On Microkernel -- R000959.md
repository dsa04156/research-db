## 요약·초록

With the growing demand for edge intelligence, traditional embedded operating systems face challenges in resource-constrained environments, including weak security isolation and poor adaptation to intelligent computing. These limitations hinder their ability to meet edge devices' dual requirements for real-time performance and security. This paper proposes a lightweight microkernel real-time operating system design for edge computing environments, focusing on both lightweight implementation and security assurance. The system enhances system security while efficiently supporting lightweight neural processing units (NPU). Built on a microkernel architecture, it decouples non-critical functions to user-mode service components, implementing core functionalities exclusively in kernel mode. It establishes a fine-grained resource isolation mechanism independent of traditional complex access control models. Specifically designed for lightweight NPU in edge devices, the system features an AI inference task framework that enables concurrent coordination and secure isolation between microkernel tasks and NPU computations. Through field testing in power industry quality inspection scenarios, the system demonstrates reliable lightweight AI computing support while maintaining real-time scheduling performance, showcasing significant potential for widespread adoption in edge intelligence applications.
