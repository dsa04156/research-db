## 요약·초록

How do you make AI written code more trustworthy? The answer is through harness engineering. See, without a harness, the answer is usually pretty manual. So engineers feed it context, watch each step, review diffs, and then fix the same mistakes over and over again. Harness engineering turns that supervision into a system. That's the whole goal here. It's everything around the model, instructions, context tools, permissions, checks, and review loops. But the real question is how does it work? So firstly, docs and rules provide context, tools and permissions, bound its actions, and then tests and linters feed failures back so that the agent can correct the code. So that means harness engineering doesn't mean engineers stop writing code....
