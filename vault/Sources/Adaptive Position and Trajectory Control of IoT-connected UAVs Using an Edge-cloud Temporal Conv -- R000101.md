## 요약·초록

Unmanned Aerial Vehicles (UAVs) are increasingly used in the Internet of Things (IoT) for surveillance, environmental observation, and smart infrastructure inspection.The traditional models find it challenging to learn over time, and thus computational latency limits their application to real-time adaptive navigation of UAVs.This study aims to resolve these limitations by proposing a cloud-edge-based Temporal Convolutional Network (TCN) based adaptive control system of an IoT-linked UAV system.The proposed model is a combination of distributed edge-cloud computing and deep-temporal learning that would facilitate the low-latency trajectory control.TCN is responsible for learning temporal flight patterns from sequential UAV telemetry data and predicting control signals for trajectory stabilization.In the UAV Telemetry Dataset with the Waypoint Navigation, time synchronization, noise filtering, and normalization are performed on the UAV telemetry data to form a temporal sequence of states.The implementation system was done in a Python setup with an edge computing node that runs on ARM Cortex processors.Experimental analysis shows a better trajectory tracking accuracy of RMSE 0.68 m and MAE 0.54 m, and a lower convergence time of 1.79 s, and adaptation rate of 0.71 s.The framework proposed is 51.2% low in control latency and better in resource efficiency by 14% of the conventional controllers.The model has better stability on trajectories, lower communication lag, and outstanding computational efficiency compared to traditional PID and LSTM-based models, and, therefore, is applicable in real-time UAV control in the dynamic IoT-based systems.
