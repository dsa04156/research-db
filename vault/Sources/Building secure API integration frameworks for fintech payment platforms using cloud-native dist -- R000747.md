## 요약·초록

The rapid expansion of digital financial services has transformed the global payments ecosystem, with fintech platforms increasingly relying on cloud-native architectures and application programming interfaces (APIs) to deliver secure, scalable, and real-time financial transactions. Open banking initiatives, embedded finance, digital wallets, instant payment networks, and cross-border payment services have accelerated API adoption, enabling seamless interoperability between financial institutions, third-party providers, merchants, and consumers. However, the growing interconnectedness of fintech ecosystems has simultaneously increased exposure to cybersecurity threats, API abuse, identity fraud, distributed denial-of-service attacks, data breaches, and regulatory compliance challenges. Conventional API integration approaches often struggle to provide the resilience, scalability, observability, and security required to support modern distributed financial applications operating across multi-cloud environments. This paper proposes a secure API integration framework founded on cloud-native distributed systems engineering practices to strengthen the security, reliability, and operational performance of fintech payment platforms. The framework integrates microservices architecture, API gateways, service mesh technologies, zero-trust security principles, OAuth 2.0 and OpenID Connect authentication, container orchestration, event-driven communication, distributed tracing, and continuous monitoring to achieve robust transaction processing and secure service interoperability. By combining cloud-native engineering with advanced API security mechanisms, the proposed framework enhances payment integrity, fault tolerance, regulatory compliance, operational scalability, and cyber resilience while supporting real-time digital financial services and future intelligent fintech ecosystems.
