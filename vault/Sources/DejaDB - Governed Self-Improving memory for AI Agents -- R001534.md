## 요약·초록

DejaDB is an open-source, governed self-improving memory engine for AI agents: Facts in a knowledge graph; skills as vectors Immutable, hash-chained history with point-in-time queries Context Assembly Languge (CAL is all you need) Microsecond recall with no server in the recall path The goal: memory that stays current, shows its receipts, and can be rolled back when an agent learns the wrong thing
