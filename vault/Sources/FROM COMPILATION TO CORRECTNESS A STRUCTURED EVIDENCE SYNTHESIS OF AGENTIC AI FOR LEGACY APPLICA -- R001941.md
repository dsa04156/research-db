## 요약·초록

Agentic coding systems increasingly perform repository search, multi-file editing, build and test execution, and iterative repair, making legacy application modernization a realistic target for automation.Yet the empirical evidence is fragmented: industrial deployments report substantial productivity gains, while several migration benchmarks report sharp declines as tasks demand broader coordination, executable environments, and stronger behavioral guarantees.This paper presents a structured evidence synthesis of nine primary empirical studies published or publicly revised from 2025 through August 2026, supported by PRISMA-inspired selection accounting.The corpus spans an industrial identifier migration, Java runtime upgrades, environment adaptation, cross-language repository modernization, cross-framework enterprise Java migration, producer self-review, real Python dependency migration, and multi-agent legacy updates.Heterogeneous scores are not pooled; analysis uses within-study contrasts and conservative thematic coding.Several within-study comparisons show performance falling as scope or correctness requirements increase: MigrationBench reports 71.
