## 요약·초록

Interesting: DeepSeek just open-sourced their agent harness and it’s already crossed 37K GitHub stars. What’s actually interesting is how they built it. Pretty much everything is designed to be swapped out. Agent loops, models, tools, sessions, you name it. They’re all plugins. So instead of digging into the source every time you want to change something, you can just plug in your own piece. It’s basically a garage for building agents. And I think that’s where this gets really interesting.
