## 요약·초록

AWS released Pizza Bot, a self-hosted open-source inbox-style application for background agents. Runs persist as threads, completed work lands in Unread, approval-blocked work lands in Action, and delegated specialists expose their own transcripts. It supports schedules, webhooks, MCP servers, Agent Skills, multiple model providers, and opt-in folder and memory access. AWS states that it is a community project rather than an AWS service and has no AWS support or SLA.
