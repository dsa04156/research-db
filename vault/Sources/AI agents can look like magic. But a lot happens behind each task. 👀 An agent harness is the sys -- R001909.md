## 요약·초록

Building an agent is one of the most important skills right now if you want to get an a I engineering job. Here's exactly how it works under the hood and the free resource to help you build one. Step 1, the agent loop. The harness takes the user's request, combines it with instructions and context and sends everything to the model. If the model requests a 2, the harness runs step 2, returns to it and repeats until the agent produce a final answer. Step 2, the tool layer. Give the model tools for web search, database queries, file editing, code execution, really anything in it. But every tool should have a clear schema, validated inputs, timeouts and permission....
